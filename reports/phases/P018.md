## Objective

Launch a protected Chromium Persona through a controlled synthetic exit and independently verify that observed browser egress matches the selected route, without requiring real Mullvad configuration.

## Implemented

- T018.1 — added a deterministic IPv4-loopback SOCKS5 fixture with kernel-selected ports, remote-domain CONNECT parsing, controlled HTTP identity responses and independent route identities. Two fixtures can represent distinguishable selected/unselected exits.
- T018.1 — added a raw SOCKS observer used for pre-launch forwarder verification. The fixture correctly treats fragmented TCP CONNECT messages as incomplete input and tolerates expected Chromium connection cancellation while retaining unexpected client errors.
- T018.2 — extended `ChromiumBrowserManager` with a bounded protected proxy option that accepts only `127.0.0.1:<valid-port>` and constructs the Chromium SOCKS proxy switch internally. A protected proxy request cannot silently reuse an already-running Persona because proxy configuration is process-immutable.
- T018.2 — added `ProtectedChromiumManager`, which owns the protected ordering: closed-Persona check → router lease → independent forwarder egress verification → Chromium launch through the leased loopback endpoint → independent browser egress verification.
- T018.2 — protected launch mismatch/failure cleans up fail-closed. Preflight mismatch releases the lease without launching Chromium; browser-verification failure closes the browser before releasing the lease; normal close is idempotent and closes the browser then releases the lease.
- T018.3 — added real pinned-Chrome acceptance using the actual typed `NativeRouterClient`, a local Unix control fixture selecting between two synthetic exits, the production protected-launch coordinator, production BrowserManager and CDP observation of the page reached through the SOCKS route.
- T018.3 — the real browser test selects `route-alpha`, independently observes `synthetic-exit-alpha` both before launch and from browser-rendered network content, proves the unselected beta exit sees no protected test traffic, and proves the lease is explicitly released on close.
