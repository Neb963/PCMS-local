## Objective

Define .pcmsmod authority/package contracts and a bounded archive parser.

## Implemented

- Added strict `ModuleManifestV1` parsing for schema version, conservative module identity, semantic version/API ranges, package entrypoints, capability authority, service dependencies, state schema version and HTTPS update metadata.
- Added a dependency-free bounded `.pcmsmod` ZIP parser with immutable input copying, original-byte SHA-256 identity, stored/deflate handling, CRC validation and required manifest/backend/UI checks.
- Rejects traversal/absolute/Windows/non-normalized paths, duplicate normalized paths, file/directory conflicts, unsafe links/devices/special files, encryption/unsupported ZIP flags and methods, ZIP64/multi-disk archives, oversized archives/entries/manifests, excessive aggregate expansion and high compression-ratio bombs.
- Added deterministic ZIP fixture construction plus adversarial unit coverage for archive attacks and invalid/unknown manifest authority.

## Deviations / ADRs

- No ADR required. The parser deliberately uses Node built-ins rather than adding an archive dependency, keeping the P006 authority surface small and deterministic.
- ZIP64 and multi-disk archives are rejected rather than supported; both are unnecessary for the bounded V1 package limits.
